# Datasheet: <dataset name>

Generated by `eos scaffold ml`; yours to edit. Questions adapted from "Datasheets for Datasets" (Gebru et al.,
https://arxiv.org/abs/1803.09010). Answer briefly; "unknown" is a valid answer and worth recording.

## Motivation

- Why was this dataset created, and by whom?
- Which decisions or models is it meant to support?

## Composition

- What does one row represent? How many rows, over which period?
- Is there a label? How is it defined, and how long after the event does it arrive?
- Does it contain personal data? Which fields, and how are they classified (see the data contract)?
- Known gaps, duplicates, or groups that are under-represented?

## Collection

- How and from which systems was it collected? Who could see it?
- Were people told, and did they consent where that is required?

## Preprocessing

- Cleaning, filtering, deduplication and joins applied (link the code and commit).
- Was any pseudonymisation or aggregation applied? Note that pseudonymised data is still personal data.

## Uses

- Uses it is suitable for, and uses it must not be put to.
- Versioning: where is each version stored and how is it pinned (commit, DVC/lakeFS reference, snapshot date)?

## Maintenance

- Owner and contact. How are errors reported and fixed?
- Retention period and deletion process.
