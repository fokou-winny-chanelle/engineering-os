# Code of Conduct

This project follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/). By taking part in this project (issues, pull requests, discussions), you agree to follow it.

In short: be respectful and constructive, assume good intent, and focus on the work. Harassment, personal attacks and discriminatory language are not accepted.

**Reporting.** To report a conduct problem, contact the maintainer privately through the GitHub profile of [@fokou-winny-chanelle](https://github.com/fokou-winny-chanelle). Do not use a public issue. Reports are handled confidentially. The maintainer may remove content, or block people who break this code, as described in the Covenant's enforcement guidelines.
