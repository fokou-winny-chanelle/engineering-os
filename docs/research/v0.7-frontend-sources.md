## 5. Validation on a real app (2026-10-10, box clock WAT)

- Playwright (system Chrome) **found two real problems in the first CSP template**: (1) with Cache Components the home page was prerendered, so its scripts had no nonce and Chrome blocked all of them; the page needs per-request rendering (`export const instant = false` worked; `await connection()` outside Suspense fails the build under Cache Components); (2) `next/image` writes `style="color:transparent"`, which a style nonce does not cover. The template now allows exactly that hash (`'unsafe-hashes' 'sha256-zlqnbDt84zf1iSefLU/ImC54isoprH/MRiVZGskwexk='`, computed locally and matching Chrome's report), and the ref and template comments explain the rendering requirement. After both fixes: header test, no-violation test and the axe smoke test (WCAG 2.0–2.2 tags) pass.
- Lighthouse CI 0.15.1 (3 runs, system Chrome): all assertions pass (median LCP 1,812 ms, TBT 71 ms, CLS 0, script 143,526 B, total 225,835 B). Lowering the script budget to 1,000 B makes `lhci autorun` exit 1, so the assertions are live. One lab run on this box, not a field measurement.
