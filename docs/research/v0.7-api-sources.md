# API design area: source survey (verified 10 October 2026)

Stage 4 of the knowledge library (docs/LIBRARY.md checklist, step 1). Every source below was opened on 10 October 2026 and the facts the refs rely on were checked against its text (copies were fetched and grepped, not recalled). Verdicts follow the import policy in `v0.7-external-sources.md`: **Import** (vendor pinned), **Adapt** (our own text, cited), **Link** (cite only).

## 2. Enforcement decisions
- **Spectral ruleset** (`.spectral.yaml`, scaffold `api-contract`): extends `spectral:oas` recommended and adds 13 `eos-*` rules: problem+json on 4xx/5xx, at least one 4xx per operation, no bare-array JSON bodies, list GETs (body has an `items`/`data`/`results`/`value` array) need a page size and a cursor, page size has a maximum, offset pagination is flagged (info), kebab-case paths with `:verb` custom methods, no CRUD verbs in paths, POST takes an `Idempotency-Key` header (info), deprecated operations need `x-sunset`, every operation has a security requirement (global or its own; `security: []` marks public endpoints explicitly), money properties are not `type: number`, `*_at`/`*At` properties are `format: date-time`. Tested with Spectral 6.17.0 against a passing and a failing fixture; each rule fires exactly where expected and the passing spec is clean. Spectral cannot see runtime behaviour, so the rules check the contract only.
- **oasdiff gate upgraded, not replaced** (tested locally with the oasdiff v1.33.0 binary, checksum verified, the version the action's Dockerfile uses: without the days flags a deprecation with no `x-sunset` passes; with them it fails as `api-deprecated-sunset-missing`, a sunset 30 days out fails as `api-sunset-date-too-small`, 200 days out passes; a new required request property fails). With `review: false` the action's entrypoint never calls its comment or telemetry functions (read at the pinned SHA): action already at the latest release v0.1.18 (SHA verified). Now passes `deprecation-days-stable: 180` and `deprecation-days-beta: 31` explicitly (the README states defaults, but `action.yml` sets none, and 0 disables the check) and `github-token: ""` so the job stays read-only and posts no comments.
- **Schemathesis job** (`api-fuzz.yml`): runs `uvx schemathesis==4.30.1` directly with our SHA-pinned setup-uv. The official `schemathesis/action` v3.0.0 uses tag-pinned (not SHA-pinned) third-party actions internally and installs the latest Schemathesis, which conflicts with our pinning rule. The start step is rendered per stack (uvicorn for FastAPI, flask for Flask, build + start for Node) and is meant to be edited; it must use a disposable database. Smoke-tested locally: the exact command line ran against a two-route FastAPI app and reported its undocumented 404 responses.
- **Not enforced (judgement calls)**: resource modelling quality, choosing GraphQL or gRPC, webhook retry design, rate-limit numbers, and Pact adoption. These are covered by refs and the eval set. `buf breaking` and AsyncAPI lint are documented in the refs but not scaffolded (no proto/AsyncAPI files assumed).
