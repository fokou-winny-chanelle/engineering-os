# Design / UX area: source survey (verified 10 October 2026)

Stage 8 of the knowledge library (docs/LIBRARY.md checklist, step 1). Every source below was opened on 10 October 2026 and the facts the refs rely on were checked against its text (pages fetched and grepped, not recalled). Pages that only render with JavaScript (m3.material.io, the Apple HIG web pages, the UNESCO UIS data browser) were not cited for facts we could not read; we used the Apple HIG JSON documents, the Android developer docs and the World Bank API instead. `systeme-de-design.gouv.fr` (DSFR) answered 403 to our fetcher, so it is **not** cited.

## 3. Enforcement added (stage 8)
| Rule from the refs | Check |
|---|---|
| tokens follow DTCG 2025.10 (types, units, aliases resolve, no cycles, names) | `eos design check` (errors); legacy string colours/dimensions are warnings (Style Dictionary still accepts them) |
| text/background token pairs meet WCAG 2.2 AA | `eos design check` contrast: DTCG pairs (`*-foreground`/`on-*` naming or `design.contrast_pairs`) and CSS custom properties per theme block (`:root`, `.dark`) |
| components use tokens, not raw colours | generic-look lint: raw hex/rgb/hsl/oklch colours and Tailwind arbitrary colours in component files |
| avoid the documented AI defaults | generic-look lint: purple/indigo/violet gradient utilities, unchanged shadcn theme values, Inter/Roboto/Geist/system fonts as the only families, emoji used as UI icons, heavy use of the stock Tailwind palette |
| motion respects reduced-motion | lint: animations or transitions with no `prefers-reduced-motion` / `motion-reduce:` / `useReducedMotion` anywhere |
| the token build works with the pinned tool | `DesignToolContractTests` (with `EOS_TEST_TOOLS=1`): Style Dictionary 5.6.1 builds the scaffold to CSS `@theme`, `.dark`, JS and Dart with no `[object Object]` and px kept as logical pixels |
| critique with screenshots against a rubric | `eos new critique` writes a dated rubric sheet; `design/critique-rubric` ref |

WCAG 2 ratio only: APCA is advisory (WCAG 3 has not chosen an algorithm and the APCA code licence is not on our allow-list).
